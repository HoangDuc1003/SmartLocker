# Góp ý của cô cho nhóm 4 (bản gốc, 2026-11-14)

Bài: "Smart Locker with Anomalous Access Detection Based on IoT Device Telemetry" (`docs/paper/smartlocker-10p.tex`, commit 13ba35f).

## Bảng 1. Kết quả kiểm tra mã nguồn
Đạt: biên dịch 89 tệp Java mức JDK 8; 47/47 test không cần SQL Server qua (các test còn lại cần SQL Server và Tomcat, nhóm tự chạy lại); JDBC thuần qua DAO/DbContext/PreparedStatement; login, logout, CRUD, phân quyền 5 vai trò; dữ liệu demo (sql/build-order.txt, run_demo_db.bat); thông số trong bài khớp mã nguồn (50 g, 300 s, 30 phút, 60 s, τ = 0.80, chân nối Table I, heartbeat 3 s, timeout 90 s) trừ các điểm ở Bảng 2.
