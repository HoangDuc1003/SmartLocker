# Ảnh minh họa cỡ ngăn tủ

Đặt ảnh vào thư mục này với đúng tên dưới đây. Ảnh có thể là `.webp` (ưu tiên) hoặc `.png`, tỉ lệ 4:3, khoảng 480 x 360 px.

| File | Cỡ | Số đo |
|---|---|---|
| `size-s.webp` | S | 20 x 20 x 20 cm |
| `size-m.webp` | M | 40 x 40 x 40 cm |
| `size-l.webp` | L | 60 x 60 x 60 cm |

Khi chưa có file, trang đặt tủ tự hiện hình SVG thay thế. Sau khi thêm ảnh, build lại để ảnh được chép vào `build/web`.
